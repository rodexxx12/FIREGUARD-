## ✅ 🧹 Code Readability & Consistency Checklist

- [✅] Follow consistent naming conventions (e.g., camelCase, PascalCase, snake_case) as agreed for this project.
- [✅] Use meaningful variable, function, class, and file names.
- [✅] Break down large functions into smaller, reusable components.
- [✅] Avoid deep nesting and overly complex conditional logic.
- [✅] Add comments where necessary for non-obvious logic (avoid redundant or outdated comments).
- [✅] Ensure consistent formatting (indentation, spacing, brackets, line length).
- [✅] Use linters and formatters appropriate for this stack (e.g., PHP-CS-Fixer, ESLint/Prettier for JS).
- [✅] Follow language-specific style guides and project conventions.
- [✅] ✅ Run automated readability checks: `composer check-readability` (excludes `device` and `FireML` directories as requested) and review/fix reported issues.
