Phone SMS Error Display - Examples

Fixed! All SMS configuration and API errors are now properly displayed to users.
1. SMS Configuration Error Alert

This alert appears at the top of the phone management page when SMS credentials are missing or invalid.

SMS Service Not Configured

The SMS service is not properly configured. Please check your .env file.

Missing Configuration:

  • SMS_API_KEY is not configured in .env file
  • SMS_DEVICE_ID is not configured in .env file

To fix this: Add the required SMS API credentials to your .env file in the root directory:

SMS_API_KEY=your_api_key_here
SMS_DEVICE_ID=your_device_id_here
SMS_API_URL=https://sms.pagenet.info/api/v1/sms/send

3. User-Facing Error Messages

When adding a phone number or sending SMS, users see these clear error messages:

API Key Mismatch (Code 406):
SMS API authentication failed. Please contact administrator to configure SMS API key correctly.
Missing API Key Header (Code 422):
Phone number added, but SMS delivery failed: API key must be required on request header. Please try resending the verification code or contact support.
Network Connection Error:
Could not connect to SMS service. Please check your internet connection.
Service Timeout:
SMS service timeout. Please try again later.
Server Error (5xx):
SMS service is temporarily unavailable. Please try again later.
4. Current Issues Detected

Based on the sms_log.txt file analysis:

Root Cause Identified
SMS API Authentication Failure

All recent SMS attempts are failing with error codes 406 and 422, indicating:

  • Code 406: API Key mismatch - The API key in the .env file doesn't match what the SMS service expects
  • Code 422: API key must be required on request header - The API key is not being sent correctly
Solution:
  1. Verify the SMS_API_KEY in your .env file is correct
  2. Verify the SMS_DEVICE_ID in your .env file is correct
  3. Contact your SMS service provider to get valid credentials
  4. Test the credentials using the SMS Log viewer
